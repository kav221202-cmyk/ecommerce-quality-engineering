# Test Scenarios

## Authentication
- Verify that a user can log in with valid credentials.
- Verify that a user cannot log in with invalid credentials.
- Verify that login fails when the username is empty.
- Verify that login fails when the password is empty.
- Verify that a locked user cannot log in.
- Verify that the user can log out successfully.

## Products
- Verify that products are displayed after successful login.
- Verify that each product displays a name.
- Verify that each product displays a price.
- Verify that each product displays an image.
- Verify that each product displays a description.
- Verify that a user can open a product's details.
- Verify that products can be sorted by name.
- Verify that products can be sorted by price.

## Shopping Cart
- Verify that a user can add a product to the cart.
- Verify that a user can add multiple products to the cart.
- Verify that the cart displays the correct number of products.
- Verify that the selected product appears in the cart.
- Verify that a user can remove a product from the cart.
- Verify that the cart is empty when no products have been added.
- Verify that a user can continue shopping from the cart.

## Checkout
- Verify that a user can proceed to checkout.
- Verify that required customer information is validated.
- Verify that a user cannot continue without required information.
- Verify that entered customer information is displayed correctly.
- Verify that the order summary displays the selected products.
- Verify that the order total is calculated correctly.
- Verify that a user can complete an order successfully.

## Order Completion
- Verify that a successful order displays a confirmation message.
- Verify that the order completion page provides the expected confirmation information.
- Verify that the user can return to the products page after completing an order.

## Navigation
- Verify that a successful order displays a confirmation message.
- Verify that the order completion page provides the expected confirmation information.
- Verify that the user can return to the products page after completing an order.

## Error Handling
- Verify that appropriate error messages are displayed for invalid login attempts.
- Verify that appropriate validation is displayed when checkout information is missing.
- Verify that the application does not allow invalid workflows to proceed.
